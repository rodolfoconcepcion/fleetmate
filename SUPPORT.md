# Support Resources for FleetMate

Welcome to the FleetMate support hub! Whether you are setting up your Tesla Fleet Telemetry mTLS certificates, integrating with TeslaMate, or publishing telemetry to Home Assistant, we are here to help.

---

## 🧭 Where to Seek Help

To ensure everyone gets prompt assistance and to prevent GitHub Issues from becoming overwhelmed, please direct your questions according to the following guidelines:

### 1. General Questions, Homelab Setup & Discussions
If you need help configuring Docker, connecting to your PostgreSQL database, setting up your MQTT broker, or generating Tesla developer credentials:
👉 **[Join GitHub Discussions](https://github.com/rodolfoconcepcion/fleetmate/discussions)**

- **Q&A**: Ask troubleshooting questions and search answered questions.
- **Show and Tell**: Share your homelab architectures and Home Assistant dashboards.
- **Ideas**: Discuss prospective features and integrations before submitting formal feature requests.

### 2. Confirmed Software Bugs
If you have found a reproducible bug or defect in FleetMate's codebase:
👉 **[Open a Bug Report](https://github.com/rodolfoconcepcion/fleetmate/issues/new?template=bug_report.yml)**

Please make sure to provide:
- FleetMate version (`fleetmate --version`)
- Python version and operating environment (Docker, Linux, bare metal)
- Detailed steps to reproduce the issue
- Relevant error logs (with sensitive keys/tokens redacted)

### 3. Feature Proposals
If you have a concrete idea for improving FleetMate:
👉 **[Submit a Feature Request](https://github.com/rodolfoconcepcion/fleetmate/issues/new?template=feature_request.yml)**

### 4. Security Vulnerabilities
If you believe you have discovered a security vulnerability or sensitive leak:
👉 **Do NOT open a public issue.** Please review our [Security Policy](SECURITY.md) and report privately via [GitHub Security Advisories](https://github.com/rodolfoconcepcion/fleetmate/security/advisories).

---

## ⏱️ Response Time & Expectations

FleetMate is an open-source project maintained by volunteers and homelab enthusiasts. 
- Discussions and community questions are typically reviewed within 2–3 business days.
- Security disclosures are acknowledged within 24 hours.
